# Contributing to Squall Parallel

Thank you for contributing to Squall Parallel. We follow strict object-oriented design rules and disciplined test coverage.

## Development Rules

1. Keep classes under 100 lines of code.
2. Keep methods under 5 lines of code.
3. Pass no more than 4 parameters into any method.
4. Controllers or top-level entrypoints instantiate no more than one object.
5. All code, comments, and commit messages must be written in English without decorative emojis.

## Running Tests

```bash
bundle exec rspec
```
